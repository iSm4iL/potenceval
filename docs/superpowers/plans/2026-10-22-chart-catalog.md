# Каталог хитов и подборки по жанрам — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Перейти от пяти песен нескольких артистов к проверенному каталогу композиций с источниками, большими жанрами и разнообразными партиями.

**Architecture:** Сборщик на Python получает публичные метаданные чартов/редакторских списков, сопоставляет конкретные записи Deezer и сохраняет JSON без аудио и временных URL превью. Статический сайт загружает готовый каталог; источник звука обновляется перед проигрыванием. Обновление запускается отдельно или небольшим локальным сервером с ежедневным обновлением и сохранением последней рабочей версии.

**Tech Stack:** Existing HTML/CSS/ES modules, Python standard library, node:test. No additional packages.

**Spec:** Утверждённый пользователем план в предыдущем сообщении: конкретные хиты из подходящих источников, скрытые составы, десять направлений, режим знакомых хитов и текущих чартов, максимум две песни исполнителя в партии, защита от недавних повторов.

## Ограничения

- Работать в текущем D:/CLGames; .git read-only, не создавать коммиты/ветки.
- Не записывать аудиофайлы, не использовать чужие ключи и не изображать работающими недоступные интеграции.
- У каждого включённого трека есть фактический источник; совпадение названия и исполнителя проверяется до включения.
- Сохранённые партии, цвета, очки, шесть длительностей и компактный экран сохраняются.
- Размер жанра определяется пригодными записями; не добивать количество случайными альбомными песнями.

## Review focus

- Совпадение с кавером, live/remix/sped-up версией или одноимённым артистом.
- Отмена/сбой обновления не портит последнюю рабочую версию каталога.
- Ограничение артистов учитывает совместные песни и техническую замену.
- Старые сохранения продолжают открываться; метаданные источника не теряются при обновлении превью.
- Состав треков/артистов не показывается до игры, поиск ответов остаётся полным.

## Результат — 22 октября 2026

- 16 публичных источников; 1425 строк проверены, 1160 подтверждённых вхождений, 1104 уникальных записи. 1074 песни распределены по игровым жанрам. Остальные 30 записей чарта относятся к другим направлениям и не выдаются в игре.
- 66 JavaScript и 27 Python проверок проходят. Дополнительно 44 партии на реальном каталоге успешно созданы и восстановлены.
- Независимый обзор: исправлены четыре найденные ошибки (свежесть жанров, замены недавних песен, русские артисты в зарубежном чарте, сохранение жанров failed source). Повторный обзор — без оставшихся замечаний.
- В браузере проверены прежнее сохранение, онлайн-превью, новый текущий чарт, точный ответ ДИНАСТИЯ с 0,5 с за 1000 очков, источник №1, восстановление очков/истории/источника, пустые жанры, экраны 1280×720 и 390×844. Размер браузера возвращён к исходному.
- Сервер на прежнем порту 4173 заменён на music/tools/serve.py с фоновым ежедневным обновлением. Реальная партия на origin 127.0.0.1 не использовалась для QA; проверка шла через localhost.
- Доступность превью зависит от региона и сервиса; временный таймаут в браузере успешно разрешился повторным запросом. Размеры некоторых направлений меньше ста: число не дополняется случайными песнями.

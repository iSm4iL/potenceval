# Угадай опенинг: музыка из историй

Музыкальная викторина:254 произведения в четырёх категориях —122 аниме,50 фильмов,37 сериалов и45 мультфильмов. За партию10 разных франшиз, четыре похожих ответа,30 секунд и одна попытка.

Запуск: `python -m http.server 4187 --bind 127.0.0.1`, открыть `/opening/`.

Песни берутся из оригинальных записей: исполнители и track ID проверены через Deezer; для аниме OP/ED-связи новых записей сверены с AnimeThemes. В фильмах, сериалах и мультфильмах используются также характерные саундтреки. `themeNote` поясняет лицензированную песню или конкретный телевизионный микс, когда это важно. Любая песня может быть известна вне данного произведения; варианты ограничены категорией и исключают ту же франшизу/запись.

## Сборка каталога

Редакторские источники — `data/anime-originals.json`, `anime-expansion.json`, `film-expansion.json`, `series-expansion.json`, `cartoon-expansion.json`. Добавление записи требует вручную сверить произведение, оригинального исполнителя, версию, preview и постер. Сборщик не ищет случайную замену отсутствующему треку.

```
python opening/tools/build_catalog.py
python opening/tools/check_catalog.py
python -m unittest discover -s opening/tools -p "test_*.py"
node --test opening/game.test.mjs
```

Сборщик формирует `data/catalog.json` и до12 похожих отвлекающих произведений для каждого ответа, учитывая жанр, настроение, исполнителя и прежние редакторские связи. Каждая категория содержит минимум10 разных франшиз. `seeds.json` и `research.ps1` — исходное исследование первой аниме-подборки, они больше не собирают весь выпуск.

## Повторные партии и звук

Очередь ставит несыгранные произведения перед сыгранными; один сезон/сиквел не вытесняет навсегда другие произведения той же франшизы. Только завершённый раунд добавляет ID в `localStorage` (`opening-played-v1`). При первом повторе начинается новый круг. История отдельная для каждой категории; при недоступном хранилище работает в памяти текущей страницы. Техническая замена не считается ошибкой и не записывается как сыгранная.

Звук загружается существующими `music/service.js` и `music/audio.js`, воспроизводится отдельным30-секундным BufferSource. Таймер запускается вместе со звуком. Аудио загружается с `cache:no-store`, остаётся в оперативной памяти; аудиофайлы не сохраняются в Git, localStorage или на сервер. Неудачная загрузка, прерывание AudioContext или возврат из BFCache предлагают замену без штрафа. При исчерпании доступных записей показывается фактически сыгранное число раундов.

Изображения загружаются с исходных CDN, их права принадлежат соответствующим владельцам; свободная лицензия не заявляется. Наличие картинки в API либо её использование в Википедии по fair use не разрешает автоматически любое повторное использование: [правила Википедии](https://en.wikipedia.org/wiki/Wikipedia:Reusing_Wikipedia_content#Fair_use_materials_and_special_requirements). Условия конкретного изображения и применимое право проверяются отдельно; коммерческая лицензия на постеры не получалась.

Игра предназначена для одного экрана и компании друзей; сетевое лобби и защита ответов от просмотра исходников не добавлены.

Три коротких превью отключены через `disabledReason` в редакторских исходниках. Сборщик не публикует их и не использует как варианты ответа.

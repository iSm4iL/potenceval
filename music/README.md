# Полсекунды — музыка онлайн

Музыкальная угадайка для одного экрана. Ведущий делится экраном и звуком в Discord, компания обсуждает ответ. Загрузка собственных файлов, аккаунт или музыкальная подписка не нужны.

## Запуск

Из корня репозитория:

```powershell
python music/tools/serve.py --port 4173
```

Откройте `http://127.0.0.1:4173/music/`. Для загрузки подборок и аудио нужен интернет. Сервер обновляет каталог метаданных в фоне раз в сутки, при сбое оставляет последнюю рабочую версию. Ключи и установка зависимостей не нужны. Для статической раздачи подходит и `python -m http.server 4173 --bind 127.0.0.1`, но тогда обновлять каталог нужно отдельно.

## Откуда музыка

Используются реальные официальные 30-секундные превью Deezer. Метаданные запрашиваются у `api.deezer.com` через поддерживаемый JSONP; браузер получает аудио прямо с `*.dzcdn.net`. У превью CORS-разрешение для Web Audio. Аудио остаётся только в оперативной памяти текущей страницы: приложение не записывает песни на диск, на сервер, в IndexedDB или localStorage; fetch использует `cache: 'no-store'`.

Пока компания угадывает текущую песню, следующая подгружается в фоне (тоже только в память страницы), поэтому после первого трека раунды стартуют без ожидания.

Превью — выбранный сервисом фрагмент композиции, не обязательно её начало. Из него открываются 0,5 / 1 / 2 / 5 / 10 / 15 секунд с одной стартовой точки. Ссылка на превью обновляется через данные трека перед загрузкой; просроченные ссылки не сохраняются в партии. Недоступные по региону или удалённые превью можно заменить без штрафа.

## Подборки и каталог

Десять широких направлений: новая школа, русский рэп, западный хип-хоп, русская поп-музыка, поп и R&B, поп-рок и альтернатива, классический рок, русский рок, электроника, инди. Карточки показывают фактическое число доступных записей; имена исполнителей и названия песен до игры скрыты.

- **Знакомые хиты** — конкретные песни из редакторских списков Apple Music, топ-100 России/США, исторического рейтинга Planet Rock и (для русского рэпа) популярного у заданных исполнителей на Deezer. Редакторский список не объявляется чартом по прослушиваниям.
- **Сейчас в чартах** — только подтверждённое присутствие в свежем топ-100 Apple Music России или США. У жанров может быть мало записей или ни одной. Источник с ошибкой или старше трёх суток в этот режим не попадает.
- **Новая школа** — жанровая разметка конкретных песен из рэп-списков, чартов и популярного у исполнителей (см. ниже).
- **Популярное у исполнителей русского рэпа** — источник `deezer-artist-top`: до пяти самых популярных на Deezer песен каждого исполнителя из списка в `sources.json` (madk1d, VILLIAN, MORGENSHTERN, PHARAOH и др.), без live/remix/sped up. Добавлен по просьбе игроков, потому что редакторские списки почти не покрывают новую школу. После ответа так и подписан: «Популярное у исполнителя на Deezer».

За партию — максимум две песни каждого исполнителя, включая совместные записи. Переиздания одной песни не повторяются. Недавние раскрытые ответы запоминаются сразу, даже если партия не закончена; новые партии и технические замены предпочитают несыгранные песни. Если свежих песен недостаточно, недавние возвращаются с сохранением лимита артистов. Доступны только длины партий, для которых хватает разных песен.

Основание включения раскрывается после ответа: ссылка на список, позиция (для рейтинга/чарта), дата проверки и пометка сохранённой версии. Поиск своего исполнителя оставлен отдельной дополнительной возможностью, до десяти верхних песен.

### Обновление

```powershell
python music/tools/build_catalog.py --workers 4
python -m unittest discover -s music/tools -p "test_*.py"
```

`data/sources.json` содержит проверенные публичные адреса и правила жанров. Сборщик получает только метаданные, сверяет название и исполнителей с Deezer, проверяет наличие превью и отбрасывает неподходящие live/remix/cover/sped-up версии. `data/catalog.json` — каталог без аудио и временных ссылок превью; `data/review.json` — отчёт о совпадениях и исключениях. Обновление атомарное; ошибки отдельных источников сохраняют их последние проверенные записи с пометкой устаревания. Последний хороший каталог не заменяется пустым результатом.

Каталог не обязан содержать ровно сто песен каждого жанра: отсутствующие совпадения не подменяются случайными альбомными треками. Для известных зарубежных направлений используются подборки разных лет; текущие релизы дополняются свежим чартом. Чарт Apple Music отражает аудиторию этого сервиса и страны, а не общее число прослушиваний во всех сервисах. Last.fm без собственного API-ключа не подключён.

Проверка альтернатив 22.10.2026: [SoundCloud API](https://developers.soundcloud.com/docs/api/terms-of-use) требует отдельных разрешений правообладателей для использования музыки в играх; [регистрация API-приложения](https://developers.soundcloud.com/docs/api/register-app) требует Artist Pro. [Spotify Developer Policy](https://developer.spotify.com/policy) запрещает игры, включая викторины. Интеграции SoundCloud, Spotify и VK в этой версии нет.

Интеграция предназначена для личного некоммерческого использования. Условия сервиса и разрешения на публичное/коммерческое использование проверяются отдельно: [Deezer guidelines](https://developers.deezer.com/guidelines), [terms](https://developers.deezer.com/termsofuse). Скрытое извлечение аудио YouTube, обход DRM и неофициальные пользовательские токены не используются.

## Ответы и подсказки

На компьютере история текущего раунда находится справа от плеера и поля ответа, на узком экране — сразу под ними. Последняя попытка всегда сверху; история сохраняется при раскрытии и перезагрузке:

- Красный: неверная песня и другой исполнитель.
- Жёлтый: исполнитель совпал, песня другая.
- Зелёный: верный трек.

Исполнители сравниваются по ID, включая соисполнителей из данных трека. Альтернативные издания одного произведения одного исполнителя засчитываются по нормализованному ключу. Подсказки ищут в подборке и онлайн; уже показанные варианты не меняют позицию при позднем ответе сети.

Очки: 1000 / 800 / 600 / 400 / 200 / 100. Повторы бесплатны. Ошибка или пропуск открывает следующую длину. За подсказку по исполнителю отдельные очки не начисляются. Сдача или последняя ошибка раскрывает ответ с нулём очков.

«Ответить», «Ещё … с» и «Сдаться» собраны рядом с вводом. Отвечать можно прямо во время прослушивания; повторное нажатие на пластинку (или пробел вне поля ввода) останавливает звук. Enter выбирает подсказку, повторный Enter отправляет ответ. После ошибки под полем остаётся заметное сообщение с введённой песней, и можно сразу вводить следующий ответ, не включая отрывок повторно. Новый раунд требует нового прослушивания.

После раскрытия ответа сразу видны вердикт, название, исполнители, обложка альбома, очки и кнопка следующего трека. За раннее угадывание эффект сильнее, за позднее — спокойнее; при включённом сокращении движения анимации отключены. При недоступной обложке остаётся музыкальный значок.

В браузере сохраняются только настройки, метаданные и прогресс игры. После перезагрузки можно продолжить партию; звук сам не запускается. Старые пользовательские файлы первой версии не удаляются из данных браузера, но онлайн-режим их не читает и не использует.

## Проверки

```powershell
node --test --test-isolation=none music/*.test.mjs genie/game.test.mjs dice/game.test.mjs
```

Длины отрывков задаются AudioBufferSourceNode, а не таймером страницы. Прогресс-бар декоративный. При уходе со страницы звук останавливается; при возвращении нет автозапуска.

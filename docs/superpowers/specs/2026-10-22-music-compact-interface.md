# Компактный игровой экран и жанровые подборки

Пользователь попросил разнообразить жанры для всей компании, убрать преобладание сольных подборок и сократить движения/прокрутку во время игры. Важно сразу видеть результат попытки, название после раскрытия, обложку и дальнейшие действия. Ранний правильный ответ должен отмечаться сильнее позднего.

## Что изменено

- Семь жанров на равных в выборе: новая школа, русский рэп, классический рок, русский рок, альтернативный рок, электроника, инди. В каждом несколько исполнителей, по пять верхних песен каждого. Новые ID проверены публичным API. Сольные карточки убраны из основного списка, явный поиск своего исполнителя остаётся дополнительной возможностью.
- На широком экране компактный плеер и форма слева, история справа. Новая попытка первой в списке; старые можно прокручивать внутри истории. На узком экране история сразу под формой.
- Кнопки ответа, расширения отрывка и сдачи собраны в строке с полем. На телефоне дополнительные действия занимают вторую компактную строку.
- Красная/жёлтая подсказка с введённым названием остаётся под полем. При ошибке допускается следующий ответ без обязательного повторного прослушивания. Новый раунд требует нового прослушивания. При отправке с клавиатуры фокус возвращается в поле после готовности плеера.
- Раскрытие показывает заметный вердикт, очки, обложку и название в верхней части, кнопку следующего трека рядом. Обложка скрыта до ответа; при ошибке изображения остаётся музыкальный значок.
- Шесть убывающих уровней конфетти. С полсекунды — золотой акцент и сильный эффект; позднее — спокойнее. Анимация запускается только при новом точном ответе. Сокращение движения учитывается.

## Проверка

Проверки `feedback.test.mjs` проверяют убывание эффекта на всех шести шагах и отсутствие победного эффекта при сдаче/последней ошибке. Проверки правил, аудио и сервиса сохраняются. Браузерная проверка выполняется на отдельном `localhost:4173`, чтобы не перезаписать партию пользователя на `127.0.0.1:4173`.

Фактически прошли 46 автоматических проверок, проверка синтаксиса и отдельная проверка навигации стрелками. Обзор кода выявил ошибку первого ArrowUp: выбиралась предпоследняя подсказка вместо последней; исправлено и проверено на фактическом обработчике.

В браузере проверены экран компьютера и ширина 390 px: поле и действия рядом, история без прокрутки страницы на компьютере, все три цвета, восстановление истории, отправка через Enter, повторный ответ без повторного прослушивания и запрет ответа без прослушивания в новом раунде. Точный ответ «цветы» тёмного принца на шаге 2 с показал загруженную обложку, 600 очков и эффект победы. На узком экране название и кнопка следующего трека находятся в видимой области, горизонтального переполнения нет. Размер окна после проверки восстановлен.

Классический рок загрузил 23 доступных уникальных трека. Один другой фрагмент при повторной загрузке не ответил вовремя; повтор и замена доступны, нейтральная замена сработала. Музыка остаётся зависимой от доступности онлайн-превью.

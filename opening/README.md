# Угадай опенинг

Статическая музыкальная викторина: 33 аниме, 10 раундов, четыре постера, 30 секунд и одна попытка. Пока доступна категория «Аниме», фильмы и сериалы обозначены «Скоро». Один экран для одного игрока или компании.

Из корня: `python -m http.server 4186 --bind 127.0.0.1`, открыть `/opening/`.

Звук загружается через существующие `music/service.js` и `music/audio.js`. Воспроизводится полный доступный фрагмент до 30 секунд с начала превью, без обрезания по правилам «Полсекунды». Таймер запускается только при воспроизведении. Аудио запрашивается с `cache: no-store` и остаётся в оперативной памяти; приложение не сохраняет его на диск или сервер. Ошибка загрузки не расходует раунд. Доступность зависит от Deezer, сети и региона.

## Каталог

`data/catalog.json` — проверенные оригинальные записи; `data/seeds.json` — редакторские кандидаты, в том числе не попавшие в выпуск. `tools/build_catalog.py` содержит одобренные ID: отсутствующие песни не заменяются похожим названием, случайным альбомным треком или кавером. `distractorIds` заданы вручную; альтернативные сезоны одной франшизы и одинаковые записи исключаются.

Обновление (Python 3, PowerShell 7, интернет):

```
pwsh -NoProfile -File opening/tools/research.ps1
python opening/tools/build_catalog.py
python opening/tools/check_catalog.py
python -m unittest discover -s opening/tools -p "test_*.py"
node --test opening/game.test.mjs
```

Перед обновлением списка одобренных ID вручную проверить версию и исполнителя, связь с аниме и сам фрагмент. Скрипт поиска сохраняет локальные исследовательские метаданные, исключённые из Git. Опубликованный каталог не содержит временных preview URL. Недоступные записи Mob Choir, Канако Ито и других исполнителей не добирались каверами. Существует 23 запасных трека для технической замены; при исчерпании запаса партия завершается с фактически сыгранным числом раундов.

## Источники

Музыка: [Deezer API](https://developers.deezer.com/api), [правила](https://developers.deezer.com/guidelines), [условия](https://developers.deezer.com/termsofuse). Интеграция для личного некоммерческого прослушивания; скачивания, офлайн-режима, рекламы и платного доступа нет. Наличие API не передаёт права на музыку.

Постеры, названия и жанры: [AniList API](https://docs.anilist.co/), исходная страница каждого аниме сохранена в `posterSource`. Изображения загружаются с CDN AniList, не копируются на хостинг. Права на постеры принадлежат соответствующим правообладателям, свободная лицензия не заявляется. При недоступности изображения показывается собственная SVG-заглушка; название ответа остаётся видимым. Jikan оказался недоступен при сборке, поэтому вместо него использован AniList.

За правильный ответ: 100 + до 300 за скорость. Отсчёт использует монотонные часы; скрытие вкладки не продлевает раунд. Ответы и ID доступны в исходниках браузера: защита от читов и сетевое лобби не входят в первую версию.

# Расширение музыкальной угадайки и постеры «До титров»

Основание: пользователь просит значительно увеличить подборки аниме, фильмов, сериалов и мультфильмов; отдельно просит настоящие постеры в «До титров» и объяснение прав на изображения.

- [x] Собрать проверенные оригинальные записи четырёх категорий. Цель:100+ аниме,45+ фильмов,30+ сериалов,35+ мультфильмов; выпускать подтверждённое количество, не добирать случайными каверами.
- [x] Добавить выбор всех четырёх музыкальных категорий, корректные подписи и счётчики. Сохранить10 раундов, четыре похожих варианта и30 секунд.
- [x] Подбирать отвлекающие ответы внутри категории по жанру/настроению/исполнителю, исключая ту же франшизу и запись.
- [x] Запоминать сыгранные произведения только в браузере: новые партии сначала используют несыгранные, затем начинают новый круг. Сбой localStorage не мешает игре.
- [x] Проверить все постеры действующего каталога «До титров», заменить манга-обложки постерами аниме, обеспечить покрытие каждой карточки и явное сообщение при ошибке картинки.
- [x] Сохранять источники, показывать атрибуцию; не называть защищённые постеры свободными и не утверждать, что fair use Википедии автоматически разрешает использование на другом сайте.
- [ ] Тесты категорий, повторов, подборки ответов и каталога; браузерная проверка аудио/постеров и375px; публикация в существующий GitHub Pages без посторонних изменений.

Технически: существующий статический JavaScript, `opening/game.js` и `app.js`; каталог строится из проверенных исходных JSON. Исходные33 аниме сохраняются. Музыка остаётся только в памяти; новый сервер и зависимости не нужны. Сбор данных по категориям делегирован независимым задачам; игровые изменения и публикация выполняются здесь.

- Итог:254 произведения —122 аниме,50 фильмов,37 сериалов,45 мультфильмов.
- Массовая браузерная проверка исходных257 записей:254 успешно загрузили и декодировали30-секундные превью и постеры. Три коротких превью исключены через disabledReason, в опубликованный каталог и ответы не попадают.
- Реальные постеры «До титров»:34 из34 успешно загружены. Манга-обложки удалены из основных и резервных изображений аниме. Кодовая иллюстрация в раунде не создаётся; при ошибке доступна повторная загрузка.
- В браузере: полная10-раундовая партия с фильмами, запуск всех4 категорий, отсутствие повторов между партиями, сохранение истории после перезагрузки. Для375px iframe подтверждена ширина документа360px без горизонтальной прокрутки.
- Независимая проверка кода: исправлены версия импорта game.js и каталога для старого кэша; исключён возврат к манга-обложкам при сбое AniList. Тесты на варианты и отключённые записи прошли.
- Перед публикацией:119 JavaScript-тестов и7 Python-тестов каталога, ошибок нет. Публикация проверяется отдельно.

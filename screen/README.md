# До титров / Until the Credits

Язык интерфейса и карточек задаёт `shared/i18n.js` (`pv.lang`). Для новых карточек добавляйте английское название, имена и описание в `catalog.en.js`, а при необходимости — перевод страны, жанров и длительности. Русские названия и псевдонимы остаются допустимыми ответами в английской версии.

Игра работает без API и без платной базы. Карточки хранятся в `catalog.js` и `catalog.extra.js`: сейчас 34 произведения. В `catalog.extra.js` добавляем новые проверенные карточки, по возможности расширяя каждую из четырёх основных кассет до 50 узнаваемых произведений. «Мама» и «Папа» остаются отдельными редакционными подборками. Число раундов выбирается перед началом игры.

Для локального просмотра можно открыть `screen/index.html` или запустить из корня сайта `python -m http.server 4173 --bind 127.0.0.1` и перейти на `http://127.0.0.1:4173/screen/`.

## Как пополнять каталог

Добавьте запись в `catalog.extra.js`: уникальный `id`, `type` (`movie` или `tv`), `category` (`film`, `series`, `anime`, `cartoon`), русское `title`, год `year`, страну `country`, длительность `runtime`, массив `genres` и собственноручно написанное краткое описание `premise`. Полезно добавить `aliases`, `director`, `cast` (до трёх известных имён) и `reference` — страницу, по которой проверены факты. Не копируйте чужие аннотации дословно. Рейтинг и сборы не выводятся: в собственном каталоге нет проверенного источника для них.

## Постеры

Картинка раунда — постер из статьи английской Википедии (у сериалов — со страницы первого сезона). Ссылки собирает `node screen/tools/posters.mjs` в `posters.js`; сами файлы не копируются, игра показывает их по ссылке, а под картинкой есть ссылка на страницу файла. Постеры защищены авторским правом. Размещение в Википедии по fair use не предоставляет автоматического разрешения на другом сайте: условия конкретного изображения и применимое право проверяются отдельно. Для новой карточки добавьте статью в словарь `WIKI` в `tools/posters.mjs` (можно `ru:Название` для русской Википедии) и перезапустите скрипт. Все текущие карточки имеют настоящий постер. В `poster-overrides.js` находятся постеры экранизаций с AniList и дополнительные источники TVMaze; при сетевой ошибке пробуется реальная альтернативная картинка, затем показывается повторная загрузка. Кодовая иллюстрация больше не подменяет постер.

В раунде постер сначала сильно размыт, кнопка «Сделать чётче» снимает размытие в четыре шага (`BLUR` и `SHARPEN` в `round.js`): так видно цвета и силуэты, но название на постере читается только в конце.

Старый `tools/build_catalog.py` и `catalog.generated.json` остались в рабочей папке как неиспользуемые файлы. Игра их не загружает и не обращается к TMDB.
